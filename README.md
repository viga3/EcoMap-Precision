EcoMap Precision - iOS Edition

Applicazione nativa per iPhone sviluppata in Swift e SwiftUI con supporto a:

•
🗺️ Mappe Interattive Apple MapKit (Standard e Satellite 3D, senza bisogno di API key a pagamento)
•
📍 GPS ad Alta Precisione (CoreLocation) con calcolo coordinate e geocodifica inversa degli indirizzi
•
🗑️ Gestione Postazioni Rifiuti: Indifferenziato, Carta, Multimateriale, Vetro, Organico, RAEE, Abiti Usati con rilevamento duplicati entro 15 metri
•
⚠️ Gestione Segnalazioni Ambientali: Abbandoni, Ingombranti, Bombole per colore, Sacchi a terra, Cassonetto bloccato, Rifiuti speciali
•
📄 Esportazione Report PDF Nativo: Generazione automatica con riepilogo dati, operatore (Michele Villani), data e condivisione su WhatsApp/Mail/File
•
💾 Archiviazione Locale & Backup: Salvataggio offline persistente con esportazione e importazione file JSON

Come Compilare e Installare su iPhone (Gratis da Windows)

Per la guida completa e dettagliata passo-passo consulta: 👉 GUIDA_INSTALLAZIONE_IPHONE.md

Sintesi rapida:

1. GitHub Actions: Al push del codice su GitHub, il flusso in .github/workflows/build-ios.yml compila automaticamente l'app su un Mac cloud gratuito e genera l'archivio EcoMapPrecision-iOS-IPA.
2. Download: Scarica il file EcoMapPrecision.ipa dalla scheda Actions di GitHub.
3. Installazione: Collega l'iPhone via cavo USB a Windows, apri Sideloadly, trascina il file .ipa, inserisci il tuo ID Apple gratuito e premi Start.
